# Design notes

Short design write-ups for non-trivial features **before or while** implementing. Not a second SRS.

## Naming

`NNN-feature-slug.md` — e.g. `001-newsfeed.md`.

## When to add

- Feed ranking/pagination choice, media pipeline, DM protocol, admin UX, etc.
- After a design chat, dump the agreed shape here so the next session does not re-litigate it.

## Template

```markdown
# Design: Title

- Phase: 1 | 2 | 3
- Status: Draft | Ready | Implemented
- Related: SRS §…, PROGRESS item …

## Goal

## UX / pages

## Data & APIs

## Open questions
```
