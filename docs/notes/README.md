# Notes (working memory)

Ephemeral-but-committed scratch for investigations and blockers. Prefer this over relying on chat history.

## What belongs here

| Pattern | Use |
|---------|-----|
| `STATE.md` | Current loop/task state if not using PROGRESS alone |
| `blocker-YYYYMMDD-short-slug.md` | Frozen scene when stuck; switch approach |
| `investigate-*.md` | Root-cause notes worth keeping |

## What does **not** belong here

- Phase checkboxes → [`../PROGRESS.md`](../PROGRESS.md)
- End-of-session handoff → [`../handoffs/`](../handoffs/)
- Durable product decisions → [`../decisions/`](../decisions/)

## Blocker template

```markdown
# Blocker: short title

- Date:
- Phase / PROGRESS item:
- Symptom:
- Tried:
- Hypothesis:
- Next experiment:
```
